# spike-html-packages-components

spike-html-packages-components is the components layer of
[spike-html-packages](https://github.com/JaimeStill/spike-html-packages): the status badge, the entry, and the pagination, Lit with shadow roots, and their sheets. It is
built on the foundation's v0.1.0 tag as a consumer installs it, and released by tag, as the Go
workspace's repositories are. This context records only working knowledge the code and the README
do not express.
